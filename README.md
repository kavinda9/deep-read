# deep-read
This is AI powered PDF read web application

# how to run 

1) You have to get Groq,OpenAI and Google Gemini API keys from these sites. After replace your API key in .env file
Groq API: https://console.groq.com/ (for summarization)
OpenAI API: https://platform.openai.com/api-keys (for text-to-speech)
Google Gemini API: https://makersuite.google.com/app/apikey (for additional AI features)

2) Install requirements
Use "pip install -r requirements.txt" in your terminal

3) Run app.py file
